# 第四阶段：候选对比（r1）

更新日期：2026-10-29。状态：第一版已接入应用。

为当前轮到的一方，把若干候选的多个角度并排列出，供使用者判断。**不给单一的"最优"分数，也不给胜率**，原因见下面的回测。

## 回测：哪些角度和胜负有关

在加入推荐之前，先检查了常用的判断角度能否区分胜负。方法：每局把一支队伍实际所选英雄在该角度上的值加总，用蓝方减红方的差值去区分胜负，计算 AUC，0.5 表示没有信息。所有统计只用该局日期之前的比赛（`scripts/evaluate_draft_factors.py`）。

| 角度 | 训练集（1,795 局） | 验证集（522 局） |
| --- | ---: | ---: |
| 职业常见度（v1 预测概率） | 0.49 | 0.47 |
| 选手熟练度（选手近期使用比例） | 0.48 | 0.49 |
| 对线强度（15 分钟经济均值） | 0.54 | 0.47 |
| 有前排 | 0.50 | 0.48 |
| 伤害均衡 | 0.51 | 0.48 |

结论：没有一个角度能单独区分胜负。

最可能的原因有两个：一是队伍实力差距远大于 BP 本身的影响；二是双方都在针对对方选择，效果大多互相抵消。所以这些角度只能当作结构化的参考信息，不能当作"选了更容易赢"的依据。界面上的候选对比面板会直接显示这组数字。

## 列出哪些候选

- **常见选择**：v1 认为职业队伍在这种局面下最可能拿的前 8 个。
- **选手拿手**（pick 时）：再补 3 个当前空缺位置上选手近期最常用、但不在前 8 名里的英雄。
- **对手最想要**（ban 时）：再补 3 个"如果对手现在选，最可能拿"、但不在前 8 名里的英雄。

## 每个候选的角度

pick 时：

| 角度 | 内容 |
| --- | --- |
| 职业常见度 | v1 的名次和概率 |
| 选手 | 它最可能补的空缺位置、该位置选手近期使用它的比例 |
| 对线 | 对面已有该位置英雄时：15 分钟经济期望；还没有时：该英雄的对线均值；样本不足标"数据不足" |
| 阵容变化 | 选它之后前排数量、魔法伤害占比的变化 |
| 对手回应 | 选它之后，下一手最可能的 3 个动作（v1） |
| Fearless | 系列赛采用 Fearless 时提示：本系列赛后续不能再选 |

ban 时：

| 角度 | 内容 |
| --- | --- |
| 职业常见度 | v1 的 ban 名次和概率 |
| 对手需求 | 如果现在轮到对手选，它的名次和概率 |
| 对手选手 | 对手对应位置选手近期使用它的比例 |
| 对我方威胁 | 对手拿到后，对线我方该位置已选英雄的期望 |
| 机会成本 | 我方自己也可能想选它时（我方选择排前 10），标黄提示 |

"如果某一方现在选"由 `Predictor.rank_as` 计算：按该方下一次真实选人所在阶段的权重，对当前局面排序。

## 限制

- **对手回应的区分度低**：v1 对"对手下一手"的预测，基本不受我方这一手影响，所以不同候选的回应常常相同。这说明 v1 还没有学到"针对性回应"，P2 v2 的实验也得到了同样的结论。
- **有些因素还衡量不了**：团战、打法与开团能力，需要更细的机制数据；补丁变更带来的强度变化，属于 P5。
- **所有角度都是历史描述**：没有一个经过"能提高胜率"的验证。
