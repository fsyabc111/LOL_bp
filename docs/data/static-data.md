# 固定版本静态资料

采集器：`python3 scripts/collect_static_data.py`，Python 3.9+ 标准库，无第三方依赖。默认固定 `14.16.1`、`16.16.1`、`16.17.1` 与 `16.20.1`，首先读取 Data Dragon 版本列表确认存在，再读取英文 `en_US` 与简体中文 `zh_CN` 的完整英雄基础目录、装备、符文、召唤师技能目录，以及 `14.16.1`/`16.20.1` 的 11 位样例英雄技能详情（`--detail-versions` 可调整详情范围，其余版本仅目录）。没有下载图片、音频或全英雄详情。

## 重取与复现

- 默认校验已缓存响应的 SHA-256、JSON 结构与嵌入版本后复用，不把本次运行时间冒充首次获取时间。
- `--offline` 仅从已验证 raw 缓存重建，缺缓存明确失败，不打开网络。`--refresh` 重新联网；每响应最多三次尝试，超时45秒，有限退避，同时最多4个公开HTTP请求。非2xx、截断、JSON解析或语义失败均记录为失败，命令以非零状态退出。
- 可通过 `--versions 14.16.1 --champions Ahri Azir` 限定范围。该命令会重写本轮 manifest；本轮请求失败的对应旧 curated 文件会移除；未请求的旧文件不会删除。因此下游必须只按 manifest 的成功 `outputs` 清单读取，不能 glob 整个目录当成本轮事实。每个输出附 `sha256` 和 `source_snapshot_sha256` 绑定规范化内容与原始快照。
- `data/raw/static/` 保存原始响应与获取元数据，按仓库策略忽略；`data/manifests/static-data.json` 保存每个 URL、获取时间、字节数、SHA-256、请求版本和验证状态。失败请求用 `attempted_at` 记录尝试时间，仅实际收到响应字节时才记录 `retrieved_at`。仅有 manifest 无法离线重建，须同时保留 raw 快照。收集器不会将失败响应转成规范化事实。
- curated JSON 按键排序，实体按数字 ID 排序；固定 raw 可重复生成相同 curated 内容。manifest 的生成时间与缓存使用状态反映本轮运行，不要求其字节相同。

## 结构与使用边界

每版本、语言分别提供 `champion.json`、`item.json`、`runesReforged.json`、`summoner.json`。英雄以 Data Dragon 数字 `key` 作为 `id`，保留 `source_key`（例如 `Ahri`）、本语言名称和 aliases；跨语言、跨赛事应优先使用数字 ID，不能只按显示名连接。重命名/重做仍须按版本核查；这里没有建立完整 OE/Leaguepedia 名称映射。

英雄基础目录保存基础属性、成长、资源类型及来源角色标签。目录本身不含完整技能；`details/` 仅覆盖 Ahri、Azir、Corki、Gnar、KSante、LeeSin、Maokai、Rell、Tristana、Vi、Ziggs。此列表是便于验证的样例集合，不宣称覆盖全部主样本英雄。

技能记录保留 Q/W/E/R 槽位、原始 description/tooltip、冷却、消耗、范围、effect/effectBurn、vars 等。`{{ totaldamage }}` 等占位符不替换，另列 `unresolved_placeholders`；`formula_resolution=unknown` 明确表示没有解释完整公式。零值 effect 仍是来源零值，不能当作零伤害或零控制时长。成长属性未转换为任意等级数值，范围也未解释为实际命中距离。被动描述保留但不推断机制。装备及召唤师技能的原生 `effect` 字段保留，不解释为已解析公式。装备与符文文本同样属于直接观察，不能直接当作战术关系。完整装备目录包含多个地图/模式，保留 `maps`、`inStore` 等来源字段，不等同职业召唤师峡谷可购买装备集合；召唤师技能保留 `modes`，后续须按比赛模式筛选，不能直接推荐全部目录项。本轮没有实现可购买规则。

英雄、装备与召唤师技能响应必须满足嵌入 `version` 与请求版本精确一致。符文端点没有嵌入版本，只能记录 `version_verification=url_only`；不能据此声称内容级版本验收。`16.16.1`/`16.17.1`/`16.20.1` 与赛事补丁 `26.16`/`26.17`/`26.20` 的命名映射仍标为 pending，未因数字近似自动验收。`14.16.1` 与赛事 `14.16` 是补丁/构建版本关联，赛事绑定须使用比赛证据。

本批未接入 CommunityDragon 机制解析、官方热修复核对、伤害计算、能力画像、对位或组合推断。Data Dragon 可能滞后且不完整；本地事实目录不是游戏行为模拟器。使用和公开分发遵守 Riot 开发者政策及游戏资产要求。
