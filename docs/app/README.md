# 第一阶段：复盘与手动分支推演

本地 Web 应用，支持载入比赛、逐步回放选禁、查看每一步的可选英雄及不可选原因，并从任意一步创建分支手动推演。分支单独保存，不改动比赛记录。目前不含推荐、预测或阵容评价。

## 运行

前提：已用 `python3 scripts/build_dataset.py` 生成本地 SQLite（`data/processed/lol_bp.sqlite3`）。

```sh
uv venv .venv --python 3.13 && uv pip install --python .venv/bin/python -r requirements/app.txt
(cd web && npm install && npm run build)
.venv/bin/uvicorn lolbp.api:app --host 127.0.0.1 --port 8000   # 打开 http://127.0.0.1:8000
```

开发前端时另开 `cd web && npm run dev`，访问 5173 端口，`/api` 会代理到 8000。地址栏 hash 记录当前比赛、步数和分支（如 `#game=LOLTMNT02_463373&step=12`），可以收藏或分享。

## 结构

| 位置 | 内容 |
| --- | --- |
| `lolbp/draft.py` | 纯函数状态机：按先选方映射 20 步模板、计算下一步、检查合法性（本局已用、Fearless 已消耗、赛事禁用、未知英雄、空 pick）、回放历史 |
| `lolbp/repository.py` | 只读数据层：比赛、系列赛分组、逐手顺序来源、规则解析、英雄目录 |
| `lolbp/branches.py` | 分支存储于 `data/app/branches.sqlite3`（不入库）：分叉步数、可选的 Fearless 假设、用户动作 |
| `lolbp/api.py` | FastAPI 接口；存在 `web/dist` 时同时提供前端页面 |
| `lolbp/check.py` | `python3 -m lolbp.check`：全量回放，汇总与规则不一致的记录 |
| `web/` | React + TypeScript + Vite 前端：系列赛浏览、选禁面板、时间线、英雄网格、规则与证据面板、分支面板 |

## 数据与规则口径

- **逐手顺序**：优先使用与 OE 最终阵容一致的 Leaguepedia 逐手表；否则把 OE 列按模板排布，界面标明来源及实测一致率 99.83%（见[黄金集](../data/oe-order-golden-set.md)）。Leaguepedia 同队连选两手（8–9、10–11、18–19 步）的组内先后在时间线上另有提示。
- **规则字段**：每项规则带状态，界面直接显示，不把假设当作事实。
  - 选禁模板：有规则书时为"规则书确认"；否则为"实践观察"，依据是 2,376 局逐手表全部符合 20 步蛇形。
  - 跨局限制：有规则书时为"规则书确认"；否则按年份假设，2025 年起为 Fearless，此前为无限制。创建分支时可以改设，记为"用户假设"。
  - 赛事禁用：优先使用规则书名单（目前都未取得）；其次使用 Leaguepedia Data 页的 SetPatch 名单，状态为"Leaguepedia 记录"，会实际拦截；都没有时为"未知"，不拦截。
  - 规则书字段可能是"规则书确认"（observed），也可能是"规则书推断"（inferred，例如 2026 Worlds 和 2025 LCK 的 Fearless 适用）。
- **合法性**：在本局已选或已禁、Fearless 已消耗（仅限制 pick）、赛事禁用、未知英雄、空 pick 这几种情况下阻止操作。禁用已消耗英雄可以执行，但会提示"该 ban 无效"（与 2026 LCK 规则 §7.7.1.2.4 一致）。
- **历史回放**：历史记录按原样显示，不被改写。与规则不一致之处在时间线上标出并列在证据面板中，因为可能是记录错误，也可能是规则假设不成立。
- **系列赛分组**：gameid 带系列号（如 `11896-11896_game_1`）时直接使用；否则把同联赛、同一对队伍、相隔 6 小时内的比赛串成一个系列赛。局序不连续的系列赛会标出，此时 Fearless 前序局可能不全。
- **英雄池**：统一使用 16.20.1 目录（173 名英雄，带中英文名），头像在运行时从 Data Dragon CDN 加载。旧补丁中可能出现当时尚未上线的英雄，这是已知的近似处理。

## 验收（2026-10-29）

- **全量回放**：5,406 局、2,122 个系列赛（1 个局序异常）。2024 年及以后有 2,375 局使用 Leaguepedia 逐手表，其余使用 OE 列。
  - 与规则不一致的步骤只有 1 处：2024 LPL `10699-10699_game_2` 第 15 步 ban 了本局已用英雄，判断为记录问题，按原样保留。
  - 2025–2026 全部比赛在假设的 Fearless 规则下没有违规 pick。另有 4 次禁用已消耗英雄，符合规则（该 ban 无效）。这说明数据与假设一致，但不等于取得了规则书证据。
- **测试**：状态机 9 项，API 3 项（基于临时数据集，覆盖分组、回放、合法性、分支的创建、推演、撤销、删除，Fearless 假设覆盖，以及历史不被修改）。全仓离线测试共 84 项通过。
- **实际页面**：在本机浏览器检查过历史回放、分支推演，以及 500px 宽度下的布局。
