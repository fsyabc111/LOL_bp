# LOL BP

面向职业赛事分析的英雄联盟 BP 辅助系统，当前处于首批数据集建设阶段。

项目以自用、免费公开数据优先，计划支持 LPL、LCK 和全球总决赛的历史 BP 复盘与手动分支推演。推荐设计将结合赛事实际补丁、选手英雄池、阵容需求，以及同版本韩服高分排位的早期信号，展示候选选择、依据和不确定性。

- [v0.2 早期设计草案](docs/design/early-design.md)：需求边界、数据来源调查、版本与排位信号、对位与阵容克制、发力窗口、资源情景、系统架构及评估安排。
- [战术数据自动获取研究](docs/research/automatic-tactical-data-sources.md)：结构化机制资料、比赛与时间线、关系统计的来源，以及实际抽样发现和自动化路线。
- [数据使用与重建](docs/data/README.md)：本地 CSV 审计、规范化 SQLite、来源清单与代表样本。
- [当前覆盖报告](docs/data/local-audit.md)：已扫描 2023–2026 年本地文件；区分可用赛果、时间截面和未验收 BP 顺序。
- [首批数据集状态与缺口](docs/data/dataset-status.md)：5,406小局、42局代表样本、固定版本静态资料及后续验收项。
- [样本集成索引](docs/data/sample-index.md)：比赛、系列赛、英雄身份、候选补丁和规则的逐局关联及未就绪原因。
- [逐手 BP 验证器](docs/data/bp-validation.md)：按规则模板、最终阵容和 Fearless 检查独立逐手证据；样本 42 局中 35 局逐手验证通过。
- [OE 选禁顺序黄金集](docs/data/oe-order-golden-set.md)：Leaguepedia 2,376 局逐手表对照，OE 列顺序一致率 99.83%。
- [本地应用](docs/app/README.md)：Web 复盘与手动分支推演（FastAPI + React），带合法性检查、规则证据状态、下一手预测和预测反馈。
- [下一手预测](docs/model/next-action.md)：在合法候选上排序对手（或任一方）的下一手；v1 验证集 Top-5 命中 62.1%（版本热门基线 50.2%），模型按版本保存，反馈会对每个新版本重新检查。
- [阵容评估](docs/model/composition.md)：对线 15 分钟经济期望、双人组合与阵容画像；回测显示对线期望能部分反映对线结果（r≈0.22），但不能预测胜负，界面按描述性证据呈现。
- 已实现本地数据审计、规范化管道、复盘应用、下一手预测和阵容评估第一版；我方推荐和 Agent 尚未实现。数据来源真实性、完整赛程及逐手 BP 仍需分项验收。
- 技术框架、评分权重、采样阈值和最终主数据源尚未确定。

本项目为非官方项目，与 Riot Games 无隶属关系。后续使用数据、素材或发布服务时，应核对各来源的适用条款及 Riot 开发者政策。
